Explora GitHub Copilot durante todo el ciclo de vida del desarrollo de software con escenarios realistas, una aplicación completa y un backlog compartido. Planificarás los cambios, escribirás código, probarás el comportamiento, revisarás solicitudes de incorporación de cambios y gestionarás el trabajo con agentes mediante un proceso iterativo.

## Escenario

Eres desarrollador en Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con temática de programación. El backlog del equipo ya está registrado como incidencias de GitHub y puedes empezar a trabajar en ellas. Incluye tareas de funcionalidades, como el filtrado y la paginación, y mejoras de calidad, como la accesibilidad y los estándares de codificación.

## Elige tu entorno

GitHub Copilot está disponible en distintos entornos de trabajo. Elige el que mejor se adapte a tu forma de desarrollar. Cada taller comienza con su propia configuración y utiliza el escenario compartido de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente con agentes en el terminal. Trabaja con los modos Plan y Autopilot, instrucciones, habilidades, agentes personalizados, Playwright MCP, Agent Merge y prácticos comandos de barra.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agentes en paralelo, cambia entre modos de sesión, colabora en canvases y gestiona incidencias y solicitudes de incorporación de cambios de GitHub desde la aplicación de escritorio.

### [Agente de GitHub Copilot en la nube][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa el progreso y revisa las solicitudes de incorporación de cambios que abre.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo de agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
